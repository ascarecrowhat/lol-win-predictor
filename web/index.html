LoL Win Predictor beta

EUW ranked solo/duo only. Prediction uses nothing but the ten summoners and their champion picks — no live game state.
The summoner must be in a game right now. First-time lookups fetch each player's recent matches from Riot and can take a couple of minutes; repeat lookups are fast.

This is a win-probability estimator for games already in progress. It does not estimate, publish or reconstruct hidden matchmaking ratings, and it reads only data Riot's API exposes for a live game.

Beta limits: EUW ranked solo/duo only, and a small number of predictions per 10 minutes because a development API key allows 100 requests every 2 minutes while one prediction needs roughly 110.
